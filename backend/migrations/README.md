# Supabase Migrations

Run the SQL in [001_init_schema.sql](001_init_schema.sql) in the Supabase SQL Editor.

Steps:
1. Open your Supabase project dashboard.
2. Go to SQL Editor.
3. Paste the contents of 001_init_schema.sql.
4. Click Run.

This creates the base tables for profiles, clubs, memberships, events, registrations, and announcements.
